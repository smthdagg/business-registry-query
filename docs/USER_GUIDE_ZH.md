# 工商企业聚合信息查询系统 · 中文完整使用教程

> 适用版本：v1.x · 界面以浏览器访问 `http://<host>:8000` 为准
> 配套文档：[English Guide](USER_GUIDE_EN.md) · [README](../README.md)

---

## 1. 登录与角色

系统部署时若设置了 `ADMIN_PASSWORD` 或 `MEMBER_PASSWORD`，打开首页会先出现登录遮罩：

| 角色 | 初始账号 | 可用范围 |
|---|---|---|
| 管理员 | `admin` / `.env` 中 `ADMIN_PASSWORD` | 全部功能 + 设置 + 人员管理 + 操作日志 |
| 普通会员 | `member` / `.env` 中 `MEMBER_PASSWORD` | 查询 / 档案 / 图谱 / 批量 / 监控 / 历史 |

- 登录连续失败 5 次会锁定 60 秒，提示剩余等待秒数。
- 管理员可在 **设置 → 修改密码** 更换口令（≥ 6 位），在 **设置 → 人员管理** 新建/重置/删除账号。
- 未设置任何口令的自用部署：任何访客直接以管理员身份进入（仅建议本机使用）。

## 2. 快速查询（首页）

### 2.1 发起搜索

1. 顶部输入框接受：**企业名 / 法人姓名 / 统一社会信用代码 / 注册号 / 联系电话**。
2. 下拉选择角度：

| 角度 | 参与数据源 | 说明 |
|---|---|---|
| 综合 | 全部 | 任意字段模糊匹配；附带同名人员分组 |
| 企业名 | 全部 | 按企业名称检索 |
| 法人 | 风鸟 + 天眼查 | 返回人员条目（👤）+ 法人匹配公司 |
| 股东 | 风鸟 | 股东姓名检索 |
| 信用代码 | 风鸟 + 88查 + 天眼查 | 精确检索 |
| 电话 | 天眼查 + 风鸟 | 电话反查 |

3. 点 **查 询**（默认聚合全部源）或快捷芯片（查企业 / 查法人 / …）一键切角度。

### 2.2 读懂结果

- 顶部芯片行：每个源显示 `条数`（成功）、`耗时`（悬停可见）、`跳过`（悬停显示原因：未配置 Cookie / 配额用尽 / 风控）。
- **公司行**：点公司名进入档案；行尾 **档案** / **关联** 两个按钮分别进入详情页与图谱页。
- **👤 人员行**：显示 `任职 N 家`、最相关企业、地区；点 **名下企业** 进入人员页。人员行来自风鸟人员档案分组，同名不同人**各自独立成条**。
- 字段级来源：聚合模式下每行行首标注该条数据来自哪些源（风鸟/88/天眼/爱企查）。

### 2.3 筛选栏

结果页顶部提供四级级联筛选，作用于**当前已返回的结果**：

`全部省份 → 城市`、`行业门类 → 细类`、`经营状态`；右侧实时显示 `筛选后 N / 总 M 条`。人员行的省份取其任职企业分布的主要省份。

### 2.4 历史芯片

页面底部"最近查询"：点条目原样重查（含角度），✕ 删除单条，**清空历史** 一键清空（管理员可删任意历史）。

## 3. 查老板（人名搜人）

入口：导航 **查老板**，或搜索页角度切到 **法人**。

1. 输入姓名 + 选择省份（可选）→ 查询。
2. 返回**同名人员分组**列表，每组一个真实的自然人：
   - `#序号`、任职企业数、主要分布地区、注册资本最大的企业名；
   - 数据来自风鸟人员档案接口，**以独立 personId 精确区分同名**。
3. 点任一分组 → 该人员**名下全部企业**：

| 列 | 内容 |
|---|---|
| 企业名称 | 点击进档案 |
| 职务 | 法定代表人 / 股东（含比例）/ 经理 / 监事等，多职务合并显示 |
| 状态 | 存续 / 注销等 |
| 地区 | 注册地 |
| 来源 | 风鸟（精确）或天眼查（兜底口径） |

4. 省份筛选是**请求级**的（风鸟 regionId，如 340000=安徽），不是本地过滤：选安徽就只返回任职企业在安徽的人员分组。
5. 只有唯一分组时自动直达该人员，避免多余点击。

> **与"搜法人出来一堆公司名"的区别**：其他平台按法人姓名搜返回的是公司列表，同名不同人混在一起；这里返回的是**人**，先选人、再看企业。

## 4. 公司档案

从任意公司名点击进入，分区与天眼查保持一致：

| 分区 | 内容 | 主要来源 |
|---|---|---|
| 基本信息 | 信用代码、法人、注册资本、成立日期、经营状态、注册地址、经营范围、联系电话、邮箱、官网、曾用名等 20+ 字段 | 全源互补 |
| 股东信息 | 股东名、**持股比例**、认缴出资、类型（自然人/企业）；自然人股东可点进其名下企业 | 风鸟 + 爱企查 |
| 主要人员 | 高管名单与职位 | 风鸟 |
| 对外投资 | 被投资企业列表（SVIP 口径最全） | 风鸟 |
| 分支机构 | 分公司列表 | 风鸟 |

- 页头提供 **加入监控**、**在图谱中查看** 快捷操作。
- 每个字段都有来源标注；跨源字段自动互补（以优先级高的源为基准）。

## 5. 关联图谱

1. 入口：公司档案/搜索结果的 **关联** 按钮，或导航 **关联图谱** 直接输入企业名。
2. 展开逻辑（按层推进）：

```
根企业 → ① 同法人企业 → ② 自然人股东 → 股东名下企业
       → ③ 高管人员 → 其名下企业 → ④ 对外投资企业 → ⑤ 分支机构
```

3. 预算控制：**深度 ≤ 3 跳、节点 ≤ 60 个**；每个节点记录数据来源，去重后成图。
4. 画布操作：**拖拽**移动节点、**滚轮**缩放、拖背景平移；点节点弹出企业/人员入口。
5. 节点颜色区分类型（企业/人员/根节点），边区分关系类型（法人/股东/高管/投资/分支）。

## 6. 批量查询与任务中心

### 6.1 提交

"批量查询"页每行一个关键词，最多 **500 行**，支持行内角度前缀：

```
法人:张三            → 按法人姓名搜
股东:李四            → 按股东姓名搜
苏胜                 → 综合角度
91340000MA2XXXXXX    → 信用代码自动识别
```

### 6.2 执行与查看

- 提交即入后台队列（串行执行，尊重各源间隔），关闭页面不影响任务。
- **任务中心**：实时进度（已完成/总数）、取消按钮、完成后点开查看全量结果。
- 单条失败不影响整批，失败原因在任务详情中标出。

### 6.3 导出

任务结果与搜索结果均可导出：

| 格式 | 说明 |
|---|---|
| CSV | 含 BOM，Excel 直接打开不乱码 |
| XLSX | 多工作表（结果 + 元信息） |
| JSON | 完整结构化数据 |

> 所有导出对 `= + - @` 开头的单元格做了公式注入防护（自动加 `'` 前缀），防止电子表格宏钓鱼。

## 7. 监控名单

1. 公司档案页点 **加入监控**（可备注），或监控页手动添加。
2. 名单页每个条目可 **一键复查**：重新拉取该企业当前状态，与上次比对。
3. 记录最近检查时间、最近状态、累计变化次数；不再关注可删除。

## 8. 历史与日志

- **查询历史**：见 §2.4。
- **操作日志**（仅管理员，设置页）：记录 登录（成功/失败/限速触发）、查询、档案查看、批量任务、设置变更、Cookie 更新、监控操作，含操作者与来源 IP。可按需清空。

## 9. 设置（管理员）

### 9.1 数据源与 Cookie

- **切换默认源**：`all` 聚合或指定单源；搜索页默认跟随。
- **更新 Cookie**：每个源独立粘贴 Cookie 字符串，保存即时生效（权威存储 `data/cookies.json`）。
- **导入 Cookie 文件**：上传自动识别的四种格式——
  1. Netscape `cookies.txt`（浏览器插件导出）
  2. JSON 数组（EditThisCookie 等）
  3. Header 字符串 `k1=v1; k2=v2`
  4. cURL 命令（DevTools → Copy as cURL）
- **连通性探测**：对每个源发一次最小请求，返回 `OK/失败原因/示例企业/耗时`。
- **保活**：后台每 30 分钟（可配）对已配置源做轻量保活，延缓 Cookie 失效。

### 9.2 账号

- **修改密码**：验旧设新（≥ 6 位）。
- **人员管理**：新建 admin / member、重置密码、调整角色、删除账号。

## 10. 故障排查速查

| 现象 | 原因 | 处理 |
|---|---|---|
| 某源芯片显示"跳过" | 未配置 Cookie / 配额用尽 / 风控 | 悬停看原因；去设置页更新对应 Cookie |
| 天眼查每次只回 5 条 | 接口单页硬限制 | 正常现象；靠聚合互补 |
| 爱企查 0 条但芯片显示成功 | 站点改版，登录态搜索偶发空 | 正常现象；等接口恢复 |
| 风鸟报"配额已用尽" | 游客/登录当日配额耗尽 | 换 SVIP Cookie；次日重置 |
| 88查返回非 JSON | 匿名滑块风控 | 浏览器打开 88cha 搜一次，更新 Cookie |
| 登录后立刻又要求登录 | 浏览器禁了 Cookie | 允许站点 Cookie；勿用无痕模式（除非设置允许） |
| 提示"用户名或口令错误" | 账号不存在或密码错 | admin 口令来自 `.env` 的 `ADMIN_PASSWORD`；忘记可由另一管理员重置 |

## 11. 配额与使用建议

- 各源均为第三方公开接口，系统已内置每源最小间隔；**不要**用脚本高频轰炸。
- 建议日常用聚合模式（一次请求多源互补），批量任务放在低峰时段跑。
- Cookie 属于敏感凭据：只在设置页/`data/cookies.json` 管理，不要写进截图或公开文档。
